# Live shapes of FMP's ordinary endpoints, as this SDK reads them.
#
# The *-bulk endpoints are NOT here — they are separately throttled and FMP restricts keys that call
# them often, so they have their own opt-in sweep and their own file. See baseline-bulk.txt.
#
# Measured 2026-08-27. Regenerate — after checking the diff is drift and not
# a break — with:
#
#     FMP_API_KEY=… FMPDOTNET_UPDATE_SMOKE_BASELINE=1 \
#         dotnet test tests/FmpDotNet.SmokeTests
#
# `set` means the property carried a value on at least one row FMP returned.
# `null` means it was null, blank or empty on every one of them.
